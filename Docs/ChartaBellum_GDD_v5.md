# 炮火与K线 (Charta Bellum)

## 系统设计策划案 v5.0

**文档性质**：最终开发执行标准  
**覆盖范围**：核心循环、金融系统、将军系统、战斗系统、局外循环、UI规范、数值配置  
**设计目标**：金融投机策略游戏，玩家通过操纵战局影响军需品价格获利

---

# 第一章：核心概念

## 1.1 游戏定位

回合制金融投机策略游戏。玩家扮演军需掮客，通过操纵战局影响军需品价格，从价格波动中获利。

**美术风格**：拿破仑时代锡兵沙盘  
**时代背景**：模糊化处理，不绑定具体历史事件

## 1.2 核心幻想

> "战场是我的K线图，士兵的生命是我的筹码。"

玩家不是将军，而是战争背后的金融操盘手。胜利的标准不是攻城略地，而是账户余额。

## 1.3 核心循环

```
判断 → 布局 → 操纵 → 收割

判断：观察战局与将军状态，预测价格走向
布局：通过金融工具（现货/期货/做空）建立仓位
操纵：通过干涉将军行动影响战局
收割：价格变动，仓位盈亏结算
```

## 1.4 设计支柱

| 支柱 | 含义 | 实现方式 |
|------|------|----------|
| **市场与战场联动** | 战局→需求→价格，玩家可操纵战局来操纵价格 | 三因子定价模型、指令消耗驱动供需 |
| **高风险高回报** | 杠杆放大收益也放大风险 | 20%保证金期货、14%爆仓线 |
| **可预测的不确定性** | 结果不可完全控制，但可通过信息判断概率 | 将军性格权重、战术星级、随机事件 |
| **道德灰度** | 最赚钱的策略往往伴随最大的道德代价 | 做空国运、故意溃败、卖国求荣 |

## 1.5 胜负框架

### 战役结束条件（触发器）

| 条件类型 | 触发条件 | 说明 |
|----------|----------|------|
| **全面崩溃** | 任意一条战线Grid 1被占领并保持1回合 | 己方战败 |
| **斩首胜利** | 任意一条战线Grid 5被占领并保持1回合 | 己方胜利 |
| **僵局超时** | 到达最大回合数且Grid 1未丢 | 停战 |

### 财务结算（记分牌）

| 军事结果 | 净资产 ≥ 目标 | 净资产 < 目标 |
|----------|--------------|--------------|
| **Grid 5 占领** | 完美胜利：本金+利润+奖金 | 苦涩胜利：没收本金 |
| **Grid 1 沦陷** | 冷血胜利：本金+做空暴利 | 彻底失败：没收本金 |
| **僵局超时** | 平庸胜利：本金+利润 | 白忙一场：没收本金 |

**核心设计意图**：战役的军事结果与玩家的财务成功完全解耦。国家可以胜利但玩家破产，国家可以灭亡但玩家暴富。

# 第二章：资源系统

## 2.1 资源分类

### A. 金融资产（可交易）

| 资源 | 代号 | 定义 | 用途 |
|------|------|------|------|
| **进攻指数** | ATK | 代表激进扩张的金融衍生品 | 干涉将军执行进攻 |
| **防守指数** | DEF | 代表保守避险的金融衍生品 | 干涉将军执行防守 |
| **撤退指数** | RET | 代表止损/做空国运的金融衍生品 | 干涉将军执行撤退 |

**硬性规则**：
- 指令不自动发放，必须从市场购买
- 玩家回合开始时手中指令数为0（除非有库存）
- 干涉将军必须消耗现货

### B. 消耗品资源

| 资源 | 范围 | 定义 | 归属 |
|------|------|------|------|
| **兵力 (HP)** | 0-20 | 部队规模，对应沙盘上锡兵数量 | 将军个体 |
| **后备役 (Reserves)** | 0-N | 国家兵员总池，所有恢复消耗此资源 | 全局共享 |

### C. 货币资源

| 资源 | 定义 | 归属 |
|------|------|------|
| **局内现金 (Cash)** | 本局可用资金 | 战役内 |
| **私人财富 (PrivateWealth)** | 跨战役积累的真正财产 | 存档 |

## 2.2 兵力系统 (20单位制)

### 兵力状态阈值

| 状态 | HP范围 | 视觉表现 | 机制影响 |
|------|--------|----------|----------|
| **满编** | 16-20 | 16-20个锡兵站立 | 全战力 |
| **健康** | 11-15 | 明显减员 | 战力轻微下降 |
| **受伤** | 6-10 | 残部 | 战力显著下降 |
| **濒死** | 1-5 | 仅存数人 | 战力严重下降，随时溃败 |
| **溃败** | 0 | 底座移出棋盘 | 战线进入真空期 |

### 兵力恢复途径

所有恢复必须消耗全局资源**后备役 (Reserves)**。

| 途径 | 触发条件 | 效果 | 消耗 |
|------|----------|------|------|
| **战术回血 (RET)** | 执行RET指令 | HP +1 | Reserves -1 |
| **战地医院** | DEF触发精锐战术"战地医院" | HP +3 | Reserves -3 |
| **基地休整** | 回合结束时位于Grid 1 | HP +2 | Reserves -2 |
| **溃败重组** | 溃败后复活 | HP = 10（半血） | Reserves -10 |

### 后备役枯竭

当 `Reserves <= 0` 时：
- 所有回血逻辑失效
- 无法复活溃败部队
- 战线一旦溃败则永久空缺
- **金融信号**：这是做空ATK/DEF的最强信号

## 2.3 净资产计算

```
净资产 = 现金 + 指令库存市值 + 期货浮动盈亏 - 银行债务

其中：
- 指令库存市值 = Σ(持有数量 × 当前价格)
- 期货浮动盈亏 = Σ((当前价 - 开仓价) × 数量 × 方向系数)
- 方向系数：做多 = +1，做空 = -1
```

# 第三章：金融市场系统

## 3.1 三因子定价模型

### 价格公式

```
Price = P_base × (1 + Alpha) × Beta × Gamma
```

### A. 基础价格 (P_base)

静态常量，定义在战役配置中，作为指数的"锚定价值"。

| 指数 | 基础价格 | 定位 |
|------|----------|------|
| ATK | $40 | 高风险高收益 |
| DEF | $35 | 稳健资产 |
| RET | $25 | 低价/避险 |

### B. Alpha因子（基本面）

反映战局的客观状态。市场是全球投机者，他们关心的是**战斗激烈程度和指令消耗预期**，完全中立，不偏向任何一方。

**核心变量定义**：
```
P = 己方将军位置（从Grid 1出发向Grid 5推进）
E = 敌方将军位置（从Grid 5出发向Grid 1推进）
约束：E > P（双方面对面）

Gap = E - P - 1
  Gap > 0 → 脱离状态（双方不相邻，指令用于移动）
  Gap = 0 → 接触状态（双方相邻，指令用于战斗）

交战中心 = (P + E) / 2（仅接触状态下有意义）
```

**Step 1: 接触状态基础修正**

| 状态 | 所有指令Alpha基础 | 说明 |
|------|-------------------|------|
| 脱离 (Gap > 0) | +0% | 指令用于移动，消耗低 |
| 接触 (Gap = 0) | +20% | 指令用于战斗，消耗高 |

**Step 2: 交战位置修正**（仅接触状态下生效）

交战中心决定了哪类指令消耗更大：

| 交战中心 | 战场描述 | ATK | DEF | RET | 逻辑 |
|----------|----------|-----|-----|-----|------|
| 1.0-1.5 | 压迫己方基地 | +5% | +25% | +20% | 防守危机，DEF/RET刚需 |
| 1.5-2.5 | 己方腹地 | +10% | +20% | +10% | 防守压力 |
| 2.5-3.5 | 中线对峙 | +15% | +15% | +5% | 攻防平衡 |
| 3.5-4.5 | 敌方腹地 | +20% | +10% | +0% | 进攻压力 |
| 4.5-5.0 | 压迫敌方基地 | +25% | +5% | -5% | 决战时刻，ATK刚需 |

**Step 3: 临界战役修正**（全局叠加）

| 条件 | 全局修正 | 说明 |
|------|----------|------|
| 任一将军位于Grid 1 | 所有指令+15% | 基地危机，高消耗战斗 |
| 任一将军位于Grid 5 | 所有指令+15% | 决战时刻，高消耗战斗 |
| 任一将军濒死(HP 1-5) | 该战线所有指令+10% | 高风险战斗即将发生 |

**Step 4: 多战线汇总**

```
Alpha[ATK] = Avg(各战线ATK修正)
Alpha[DEF] = Avg(各战线DEF修正)
Alpha[RET] = Avg(各战线RET修正)
```

**示例计算**：

场景：左翼 P=2, E=3（接触，交战中心=2.5）；中军 P=3, E=5（脱离）；右翼 P=1, E=2（接触，交战中心=1.5）

```
左翼（接触，中心2.5，己方腹地）：ATK+10%, DEF+20%, RET+10%
中军（脱离）：ATK+0%, DEF+0%, RET+0%
右翼（接触，中心1.5，压迫基地）：ATK+5%, DEF+25%, RET+20%
  + 临界修正：己方位于Grid 1 → 全局+15%

汇总：
  ATK Alpha = (10+0+5+15)/3 = +10%
  DEF Alpha = (20+0+25+15)/3 = +20%
  RET Alpha = (10+0+20+15)/3 = +15%
```

### C. Beta因子（情绪）

反映市场的非理性波动。

**动量效应**：
```
If (上周价格涨幅 > 10%) → Beta × 1.2 (追涨)
If (上周价格跌幅 > 10%) → Beta × 0.8 (杀跌)
```

**恐慌效应**（后备役触发）：
```
If (Reserves < 20):
    ATK.Beta × 0.6  (抛售进攻资产)
    DEF.Beta × 1.5  (避险)
    RET.Beta × 2.0  (逃命)
```

### D. Gamma因子（流动性）

反映供需挤压，是逼空/逼多的核心。

```
Gamma = InitialFloat / Max(CurrentFloat, 1)

InitialFloat: 战役初始流通盘（配置常量，如50）
CurrentFloat: 当前流通盘（实时变量）
```

**效果**：
- 流通盘充足 → Gamma ≈ 1，价格平稳
- 玩家买断库存 → CurrentFloat → 0 → Gamma → ∞ → 价格暴涨

## 3.2 流通盘系统

### 初始配置

在 `CampaignConfig` 中定义：

| 参数 | 示例值 | 说明 |
|------|--------|------|
| InitialFloat_ATK | 50 | ATK初始流通盘 |
| InitialFloat_DEF | 50 | DEF初始流通盘 |
| InitialFloat_RET | 50 | RET初始流通盘 |

### 流通盘变化规则

流通盘是**实时变量**，玩家每次交易立即影响。

| 操作 | 流通盘变化 | 价格影响 |
|------|-----------|----------|
| 玩家买入现货 | Float-- | 价格上涨 |
| 玩家卖出现货 | Float++ | 价格下跌 |
| 维克多买入 | Float-- | 价格上涨 |
| 军工厂产出 | Float += 产量 | 价格下跌 |

### 军工厂动态产能

每回合结算时，军工厂根据上周消耗量动态调整产能：

```
本周产能 = 上周总消耗 × 产能系数(0.9~1.1)
上周总消耗 = 玩家干涉消耗 + 维克多采购消耗

保底产能：若计算结果 < 3，则强制设为 3
```

**设计意图**：保持市场始终处于"微弱的供不应求"状态。

## 3.3 现货交易

### 买入现货

```
操作：玩家从市场购买指令
成本：当前价格 × 数量 × (1 + 手续费率)
效果：
  - Cash -= 成本
  - Holdings[type] += 数量
  - Float[type] -= 数量
  - 价格实时上涨（Gamma变化）
```

### 卖出现货

```
操作：玩家向市场出售指令
收入：当前价格 × 数量 × (1 - 手续费率)
效果：
  - Cash += 收入
  - Holdings[type] -= 数量
  - Float[type] += 数量
  - 价格实时下跌（Gamma变化）
```

### 仓储成本

每回合结算时扣除：
```
仓储费 = 持有指令总数 × $3
```

## 3.4 期货与做空

### 统一机制

游戏中所有"做空"操作在底层都是**开立期货合约**。

**UI表现**：
- 持有现货时点击"卖出" → 卖出现货
- 不持现货时点击"卖出" → 开立空单（Short）

### 期货参数

| 参数 | 数值 | 说明 |
|------|------|------|
| 到期时间 | 3回合 | 固定，不可选 |
| 初始保证金率 | 20% | 5倍杠杆 |
| 维持保证金率 | 30% | 爆仓警戒线 |

### 开仓计算

```
开多仓：
  占用保证金 = 开仓价 × 数量 × 20%
  Cash -= 占用保证金

开空仓：
  占用保证金 = 开仓价 × 数量 × 20%
  Cash -= 占用保证金
```

### 浮动盈亏

```
多仓浮盈 = (当前价 - 开仓价) × 数量
空仓浮盈 = (开仓价 - 当前价) × 数量
```

### 强制平仓（爆仓）

当浮亏导致剩余保证金不足维持线时触发：

```
动态权益 = 已交保证金 + 浮动盈亏
维持线 = 占用保证金 × 30%

触发条件：动态权益 < 维持线

做多爆仓点：价格 ≤ 开仓价 × 0.86（跌14%）
做空爆仓点：价格 ≥ 开仓价 × 1.14（涨14%）
```

### 到期结算

期货到期时按当前现货价强制交割：

```
多仓结算：
  盈亏 = (到期价 - 开仓价) × 数量
  Cash += 盈亏 + 已交保证金

空仓结算：
  盈亏 = (开仓价 - 到期价) × 数量
  Cash += 盈亏 + 已交保证金
```

### 政权崩溃清算

当Grid 1沦陷触发战役结束时：

1. **现货归零**：ATK、DEF价格强制设为$0
2. **空单结算**：按$0价格强制交割，空单获得最大收益
3. **RET价格**：视配置而定（可设为$0或保留/溢价）

**示例**：
- 玩家做空ATK 100张，开仓价$100
- 政权崩溃，ATK → $0
- 盈利 = (100 - 0) × 100 = $10,000

## 3.5 银行借贷

| 参数 | 数值 |
|------|------|
| 利率 | 5%/回合（复利）|
| 额度 | 净资产 × 1.5 - 当前债务 |
| 限制 | 净资产为负时无法借款 |

```
借款操作：
  Cash += 借款金额
  Debt += 借款金额

每回合结算：
  Debt = Debt × 1.05

还款操作：
  Cash -= 还款金额
  Debt -= 还款金额
```

| 己方 | 3位 | 玩家干涉 | 全属性可见 |

### 动态属性

| 属性 | 范围 | 初始值 | 可见性（己方/敌方）|
|------|------|--------|-------------------|
| 兵力 (HP) | 0-20 | 16 | 可见/可见 |

| 士气 (Morale) | 0-100 | 60 | 可见/不可见 |

## 4.2 信任度系统

信任度影响将军的抗命概率和出价态度。**玩家不可见此属性**。

### 信任度变化

| 事件 | 变化 |
|------|------|
| 顺势强化（同类型指令干涉） | +5 |
| 强制篡改（不同类型指令干涉） | -15 |
| 因玩家指令战斗胜利 | +5 |
| 因玩家指令战斗失败 | -5 |

### 信任度影响

| 信任度范围 | 抗命概率 | 行为表现 |
|------------|----------|----------|
| 80-100 | 0% | 完全服从 |
| 50-79 | 0% | 正常服从 |
| 30-49 | 20% | 偶尔抗命 |
| 0-29 | 50% | 经常抗命 |

**抗命处理**：
- 将军拒绝执行玩家指定的指令
- 自行按性格权重选择行动
- 玩家消耗的现货不退还

## 4.3 士气系统

| 战斗失败 | -10~20 |
| 收到想要的指令 | +5 |
| 收到不想要的指令 | -5 |
| 友军溃败 | -10 |

### 士气对战斗的影响

| 士气范围 | 造成伤害修正 | 受到伤害修正 | 特殊效果 |
|----------|-------------|-------------|----------|

## 4.4 将军性格

| 性格 | 行为特征 | 缺陷 |
|------|----------|------|
| **狂热型** | 激进好战，喜欢进攻 | 厌恶撤退，残血时更疯狂 |

| 投机型 | 33 | 33 | 34 |

## 4.5 将军AI决策逻辑

### 意图生成公式

```
FinalWeight = BaseWeight × HP_Modifier × Grid_Modifier
概率 = FinalWeight / Σ(所有FinalWeight)
```

### 兵力修正 (HP_Modifier)

| 状态 | HP | 狂热型 (A/D/R) | 保守型 (A/D/R) | 投机型 (A/D/R) |
|------|-----|----------------|----------------|----------------|
| 满编 | 16-20 | 1.2/0.8/0.5 | 1.0/1.0/1.0 | 1.1/1.0/0.9 |
| 健康 | 11-15 | 1.1/0.9/0.7 | 0.8/1.1/1.2 | 1.0/1.0/1.0 |
| 受伤 | 6-10 | 1.0/1.0/1.0 | 0.5/1.2/1.5 | 0.8/1.0/1.2 |
| 濒死 | 1-5 | **1.5/0.5/0** | **0/1.5/3.0** | **0.2/1.0/2.0** |

**设计意图**：
- 狂热者残血时ATK权重反升，RET归零（玉碎冲锋）
- 保守者一掉血RET权重暴增（求生本能）

### 位置修正 (Grid_Modifier)

| 位置 | 场景 | ATK | DEF | RET |
|------|------|-----|-----|-----|
| Grid 1 | 己方基地 | 1.5 | 2.0 | **0**（禁止）|
| Grid 2 | 腹地 | 1.0 | 1.2 | 1.5 |
| Grid 3 | 中线 | 1.0 | 1.0 | 1.0 |
| Grid 4 | 敌方腹地 | 1.2 | 1.0 | 0.8 |
| Grid 5 | 敌方基地 | **3.0** | 1.5 | 0.1 |

**硬性规则**：
- Grid 1 时RET权重强制为0（退无可退）
- Grid 5 时ATK权重极大（试图终结战役）

### 示例计算

**场景**：狂热型将军，HP=3（濒死），Grid 4

```
1. 基础权重：ATK=70, DEF=20, RET=10
2. HP修正（濒死-狂热）：ATK×1.5=105, DEF×0.5=10, RET×0=0
3. 位置修正（Grid 4）：ATK×1.2=126, DEF×1.0=10, RET×0.8=0
4. 最终概率：ATK=92.6%, DEF=7.4%, RET=0%

结果：这个狂热者大概率会选择送死冲锋。
```

## 4.6 意图与干涉系统

### 默认意图

回合开始时，将军根据性格AI自动生成一个意图。

**UI表现**：头顶显示灰色气泡（如"ATK"）

**免费规则**：如果玩家不进行干涉，将军执行默认意图，不消耗任何现货。

### 玩家干涉

玩家可以通过消耗现货来改变将军行为。

| 操作 | 现货消耗 | 效果 | UI表现 |
|------|----------|------|--------|
| **强化** | 1份同类 | 战术星级提升，士气+5，信任度+5 | 金色气泡 |
| **篡改** | 3份异类 | 强制改变指令，士气-5，信任度-15 | 红色气泡 |
| **不作为** | 0 | 执行默认意图 | 灰色气泡 |

**示例**：
- 将军想ATK，玩家拖1份ATK上去 → 强化ATK
- 将军想ATK，玩家拖3份RET上去 → 篡改为RET

## 4.7 溃败与重组

### 溃败触发

当将军HP降至0时触发溃败：
1. 底座移出棋盘
2. 战线进入真空期（无人防守）

### 重组条件

| 条件 | 要求 |
|------|------|
| 战线Grid 1未沦陷 | 必须 |
| 后备役充足 | Reserves ≥ 10 |

### 重组流程

1. 消耗Reserves -10
2. 下回合在Grid 1生成部队
3. 初始HP = 10（半血）
4. 保留原将军的性格、信任度、士气

**失败后果**：
- 若Grid 1被占 → 战线永久沦陷
- 若Reserves不足 → 无法重组，战线永久空缺

# 第五章：战场系统

## 5.1 战场结构

### 战线拓扑

```
三条战线独立运作，有联动加成

     左翼 ─── 中军 ─── 右翼

每条战线包含5个格子 (Grid 1-5)：
  Grid 1 = 己方大本营（复活点）
  Grid 3 = 中线
  Grid 5 = 敌方大本营
```

### 单位表现

- 每个将军底座预置**20个锡兵模型**
- `HP (0-20)` 直接控制可见模型数量
- 受损 = SetActive(false)对应数量的模型
- 溃败 = 底座移出棋盘

## 5.2 距离与接触判定

### 位置与距离定义

```
P = 己方将军位置（从Grid 1向Grid 5推进）
E = 敌方将军位置（从Grid 5向Grid 1推进）
约束：E > P（双方面对面，不会重叠）

Gap = E - P - 1（双方之间的空格数）
```

| 距离 | 状态 | 说明 |
|------|------|------|
| Gap > 0 | 脱离 | 双方之间有空格，不相邻 |
| Gap = 0 | 接触 | 双方相邻，可发生战斗 |

**示例**：

| P | E | Gap | 状态 | 说明 |
|---|---|-----|------|------|
| 2 | 3 | 0 | 接触 | 双方相邻 |
| 2 | 4 | 1 | 脱离 | 中间隔1格 |
| 3 | 4 | 0 | 接触 | 双方相邻 |
| 1 | 5 | 3 | 脱离 | 最大距离 |
| 1 | 2 | 0 | 接触 | 敌方压到家门口 |
| 4 | 5 | 0 | 接触 | 己方压到敌方基地 |

### 脱离状态结算 (Gap > 0)

指令仅作为移动/休整命令，不触发战斗对抗表。

| 指令 | 行为 | 效果 | 资源消耗 |
|------|------|------|----------|
| ATK | 行军 | P向敌方推进1格（P++） | 无 |
| DEF | 驻扎 | 位置不变，不回血 | 无 |
| RET | 后撤 | P向己方后撤1格（P--），HP+1 | Reserves -1 |

**注**：敌方同理，ATK使E--，RET使E++。

### 接触状态结算 (Gap = 0)

当双方相邻时触发指令对抗表。

| 己方 | 敌方 | 场景 | 己方HP | 敌方HP | 战线移动 |
|------|------|------|--------|--------|----------|
| ATK | ATK | 遭遇战 | -2 | -2 | 不动 |
| ATK | DEF | 攻坚战 | -4 | -1 | 不动 |
| ATK | RET | 追击 | 0 | 0 | P++, E++（己方推进，敌方后撤）|
| DEF | ATK | 阻击 | -1 | -4 | 不动 |
| DEF | DEF | 静坐 | 0 | 0 | 不动 |
| DEF | RET | 目送 | 0 | +1 | E++（敌方后撤）|
| RET | ATK | 撤离 | +1 | 0 | P--, E--（己方后撤，敌方推进）|
| RET | DEF | 休整 | +1 | 0 | P--（己方后撤）|
| RET | RET | 脱离 | +1 | +1 | P--, E++（双方拉开）|

**注**：HP变化为基础值，实际值受士气、战术、联动等修正。

## 5.3 战线联动

### 侧翼支援

| 条件 | 效果 |
|------|------|
| 相邻友军战线 ≥ 己方+1 | 战斗力+10%（造成伤害+1）|

### 侧翼威胁

| 条件 | 效果 |
|------|------|
| 相邻敌军战线 ≥ 己方+1 | 受到伤害+2，士气-5 |

### 半包围

| 条件 | 效果 |
|------|------|
| 两侧友军战线都 ≥ 4 | 中路战斗力+25%（造成伤害+2）|

### 被包围

| 条件 | 效果 |
|------|------|
| 两侧敌军战线都 ≤ 2 | 中路士气-15 |

## 5.4 战术系统

### 战术星级

| 星级 | 定义 | 基础权重 | 示例 |
|------|------|----------|------|
| **普通** | 标准效果 | 90 | 步兵冲锋、坚守阵地 |
| **精锐** | 强化效果 | 10 | 精锐突击、战地医院 |

### 强化算法

当玩家对将军执行"强化"操作后：

```
强化后权重修正：
  普通战术：权重 × 0.5
  精锐战术：权重 × 5.0

计算示例：
  未强化：普通90%, 精锐10%
  强化后：普通45/(45+50)=47%, 精锐50/(45+50)=53%
```

### 战术效果表

| 指令 | 星级 | 战术名 | 伤害修正 | 特殊效果 |
|------|------|--------|----------|----------|
| ATK | 普通 | 步兵冲锋 | 0 | 无 |
| ATK | 精锐 | 精锐突击 | +2 | 无视DEF减伤 |
| DEF | 普通 | 坚守阵地 | 0 | 无 |
| DEF | 精锐 | 战地医院 | 0 | HP+3（消耗Reserves 3）|
| RET | 普通 | 有序撤退 | 0 | HP+1（标准）|
| RET | 精锐 | 焦土战术 | 敌方-2 | HP+1，追击者受伤 |

### 性格对战术的影响

| 性格 | 强化ATK时 | 强化DEF时 |
|------|-----------|-----------|
| 狂热型 | 精锐概率额外+20% | 精锐概率-10% |
| 保守型 | 精锐概率-10% | 精锐概率额外+20% |
| 投机型 | 无修正 | 无修正 |

## 5.5 战斗结算流程

1. **收集指令**：获取双方将军的最终指令
2. **判定距离**：确定脱离/接触状态
3. **查表基础伤害**：从指令对抗表获取
4. **战术修正**：根据战术星级调整伤害
5. **士气修正**：应用士气加减值
6. **联动修正**：应用侧翼支援/威胁
7. **随机修正**：应用±25%波动 + 5%暴击/失误
8. **最终伤害**：取整后扣除HP
9. **战线移动**：根据对抗表执行
10. **状态更新**：更新士气、检查溃败

### 随机修正

```
随机修正 = 基础伤害 × (0.75 ~ 1.25)

暴击（5%概率）：伤害 × 1.5
失误（5%概率）：伤害 × 0.5
```

## 5.6 胜利条件检查

### 每回合结束时检查

```
1. 占领检查：
   - 若任意敌方战线Grid位置 = 1 → 标记"濒临崩溃"
   - 若任意己方战线Grid位置 = 5 → 标记"濒临胜利"

2. 保持检查：
   - 若"濒临崩溃"连续保持1回合 → 触发"全面崩溃"结束
   - 若"濒临胜利"连续保持1回合 → 触发"斩首胜利"结束

3. 超时检查：
   - 若 Week >= MaxWeeks 且 Grid 1 未丢 → 触发"僵局超时"结束
```

## 6.3 阶段详解

### 阶段 I：周报与开盘

**1. 时间推进**
```
Week++
```

**2. 费用结算**
```
// 银行利息
Debt = Debt × 1.05

// 仓储费
StorageCost = TotalHoldings × 3
Cash -= StorageCost
```

**3. 随机事件**
- 40%概率触发一个随机事件
- 同一事件不连续出现
- 公示事件内容和影响

**4. 意图生成**
- 遍历所有将军
- 根据性格AI计算意图权重
- 随机选择一个意图
- 显示灰色气泡

**5. 市场开盘**
- 计算三因子定价
- 刷新行情板

### 阶段 II：玩家操盘

**这是唯一的玩家交互阶段。**

玩家可以：
- 买卖现货
- 开立/平仓期货
- 借款/还款
- 对将军执行强化/篡改
- 查看市场情报
- 查看历史记录

**结束条件**：玩家点击"结束本周"

### 阶段 III：维克多行动

**核心规则**：维克多必须从市场购买指令才能干涉敌方将军，与玩家规则完全对称。

**1. 军事采购与干涉**
```
For each 敌方将军:
    intent = 将军默认意图
    
    // 困难模式：检查是否需要修正愚蠢意图
    If Difficulty == Hard && 意图愚蠢:
        optimalIntent = 计算最优意图
        If optimalIntent != intent:
            // 尝试篡改（需要3份指令）
            If 能获取3份optimalIntent指令:
                执行篡改
                消耗3份指令
            Else:
                放弃篡改，使用默认意图
    
    // 尝试强化（需要1份指令）
    If Float[intent] > 0 && Victor.Cash >= Price[intent]:
        Victor.Buy(intent)
        Float[intent]--
        Victor.Cash -= Price[intent]
        执行强化
    Else:
        // 垄断触发！将军只能执行默认意图，且无法强化
        将军执行未强化的默认意图
```

**2. 投机操作**（仅困难模式）
```
If 玩家持有大量ATK多单 && Victor.Holdings[ATK] > 5:
    // 恶意抛售砸盘
    Victor.Sell(ATK, Victor.Holdings[ATK])
```

### 阶段 IV：战斗推演

**按战线顺序执行**：左翼 → 中军 → 右翼

**每条战线**：
1. 检查将军是否抗命
2. 抽取战术
3. 计算伤害
4. 播放演出
5. 更新状态

### 阶段 V：回合结算

**1. 基地恢复**
```
For each Grid1的将军:
    If Reserves >= 2:
        HP += 2
        Reserves -= 2
```

**2. 溃败重组**
```
For each 溃败的将军:
    If Grid1未沦陷 && Reserves >= 10:
        Reserves -= 10
        下回合在Grid1生成HP=10的部队
```

**3. 军工厂产出**
```
For each 指令类型:
    Production = LastWeekBurn × Random(0.9, 1.1)
    Production = Max(Production, 3)
    Float[type] += Production
```

**4. 期货到期**
```
For each 3回合前开立的期货:
    执行强制交割
```

**5. 胜负检查**
```
检查占领/保持/超时条件
若满足则触发战役结束
```

# 第七章：维克多AI系统

## 7.1 角色定位

维克多·克劳斯是：
- 市场上的竞争对手
- 敌方将军的指令供应者
- 可能的金融狙击手

**核心规则**：维克多与玩家遵循完全相同的规则，必须从市场购买指令才能干涉敌方将军。这是"垄断策略"的基础——玩家买光流通盘后，维克多无法采购，敌方将军只能执行默认意图。

## 7.2 基础属性

| 属性 | 说明 | 可配置 |
|------|------|--------|
| Cash | 可用资金 | 是 |
| Holdings | 持有的指令库存 | 是 |
| Difficulty | 决策质量（简单/普通/困难） | 是 |

**玩家可见性**：维克多的现金和持仓对玩家不可见。

## 7.3 行为树

### 优先级1：军事刚需

维克多首先满足敌方将军的指令需求。

```
For each 敌方将军:
    intent = 将军默认意图
    
    // 检查是否需要干涉（困难模式下会修正愚蠢意图）
    If Difficulty == Hard && 意图是愚蠢的（如残血冲锋）:
        intent = 计算最优意图
        需要篡改 = true
    
    // 尝试获取指令
    需要数量 = 需要篡改 ? 3 : 1  // 篡改需要3份，强化需要1份
    
    If Holdings[intent] >= 需要数量:
        使用库存
    Else If Float[intent] >= 需要数量 && Cash >= Price[intent] * 需要数量:
        购买指令
        Float[intent] -= 需要数量
        Cash -= Price[intent] * 需要数量
    Else:
        // 垄断触发！
        If 需要篡改:
            放弃篡改，执行默认意图
        Else:
            将军只能执行默认意图（可能是次优选择）
```

### 优先级2：成本控制

```
If 非关键战役（如Grid 3僵持）:
    If ATK价格 > $150:
        放弃进攻，改为DEF（省钱）
    If 任意指令价格 > $200:
        放弃干涉，让将军执行默认意图
```

### 优先级3：投机狙击（仅困难模式）

```
If 玩家持有大量ATK多单:
    If Holdings[ATK] > 5:
        恶意抛售砸盘
        Float[ATK] += Holdings[ATK]
        Cash += Holdings[ATK] * Price[ATK]
    Else If Cash > 200:
        尝试做空ATK
```

## 7.4 难度影响

| 难度 | 维克多行为 | 垄断难度 |
|------|-----------|----------|
| 简单 | 只满足军事需求，不投机，不修正将军愚蠢意图 | 低（容易垄断） |
| 普通 | 军事优先，偶尔投机，不修正将军意图 | 中 |
| 困难 | 会修正将军愚蠢意图（额外消耗指令），主动狙击玩家仓位 | 高（难以垄断） |

**关键设计**：困难模式下维克多会像玩家一样"篡改"敌方将军的愚蠢意图，这意味着他需要消耗3份指令而非1份，增加了对流通盘的消耗，使玩家的垄断策略更难执行。

# 第八章：随机事件系统

## 8.1 触发规则

- 每回合开始40%概率触发一个事件
- 同一事件不连续出现

# 第九章：局外循环系统

## 9.1 玩家存档结构

```csharp
public class PlayerProfile {
    // 核心资产
    public float PrivateWealth;      // 私人财富（初始$1000）
    public float CreditScore;        // 生涯信誉
    
    // 进度记录
    public List<string> CompletedCampaigns;  // 已通关战役
    public int TotalCampaignsPlayed;
    public float HighestProfit;
}
```

## 9.2 入场流程

1. 玩家选择战役（读取CampaignConfig）
2. **检查入场费**：
   - 若 `PrivateWealth >= EntryFee`：
     - 扣除入场费
     - 入场费转入局内Cash
     - 分配初始库存（各2张）
   - 若资金不足：
     - 进入"破产保护"模式（低保教学关，EntryFee=0）

## 9.3 结算流程

战役结束时执行：

**1. 计算局内净资产**
```
NetWorth = Cash + Holdings × Price + FuturesPnL - Debt
```

**2. 判定财务结果**
```
If NetWorth >= TargetNetWorth:
    // 财务达标
    Profit = NetWorth - EntryFee
    PrivateWealth += EntryFee + Profit
Else:
    // 财务未达标
    PrivateWealth += 0  // 没收本金
```

**3. 更新存档**
```
CompletedCampaigns.Add(CampaignID)
TotalCampaignsPlayed++
HighestProfit = Max(HighestProfit, Profit)
```

# 第十二章：术语表

| 术语 | 定义 |
|------|------|
| **指数/指令** | ATK/DEF/RET三种可交易金融资产 |
| **现货** | 即时交割的指令，可用于干涉将军 |
| **期货** | 延期3回合交割的合约 |
| **做多** | 买入，赌涨 |
| **做空** | 卖出期货合约，赌跌 |
| **杠杆** | 用少量资金控制大额资产（5倍）|
| **保证金** | 期货开仓押金（20%）|
| **强平/爆仓** | 亏损过大时强制平仓 |
| **流通盘** | 市场上可交易的指令总量 |
| **逼空** | 买断流通盘导致价格暴涨 |
| **三因子** | Alpha(基本面)+Beta(情绪)+Gamma(流动性) |
| **强化** | 消耗1份同类现货提升战术效果 |
| **篡改** | 消耗3份异类现货强制改变将军指令 |
| **抗命** | 将军拒绝执行指令 |
| **溃败** | 将军HP归零，离场 |
| **后备役** | 国家兵员总池，恢复必消耗 |
| **战线** | 战争形势指标（Grid 1-5）|
| **侧翼威胁** | 相邻战线敌进我退时的惩罚 |
