# 炮火与K线 (erta Bellum)

## 原型开发策划案

**文档性质**：核心愿景与机制说明  
**目标读者**：原型开发团队  
**聚焦内容**：设计意图、机制框架、验证目标

---

# 一、游戏愿景

## 1.1 一句话描述

**你不是将军，你是战争背后的金融操盘手。**

## 1.2 核心幻想

> "战场是我的K线图，士兵的生命是我的筹码。"

玩家扮演军需掮客，通过观察战局预判市场走向，利用金融工具建立仓位，再通过干涉将军行动操纵战局，最终从价格波动中获利。

**关键体验**：
- 不是指挥战争，而是**利用**战争
- 胜利的标准不是攻城略地，而是**账户余额**
- 国家可以灭亡，但玩家可以通过做空暴富

## 1.3 目标情感

| 时刻 | 目标情感 |
|------|----------|
| 成功预判并布局 | 智力优越感："我早就看穿了" |
| 操纵战局收割利润 | 掌控感+道德灰度："我在玩弄生命" |
| 高杠杆豪赌成功 | 刺激与爽快："一夜暴富" |
| 判断失误爆仓 | 紧张与复盘欲："下次我会更小心" |
| 做空国运成功 | 黑色幽默："国家亡了，但我发财了" |

## 1.4 设计支柱

| 支柱 | 含义 | 验证标准 |
|------|------|----------|
| **市场与战场联动** | 战局影响价格，玩家可通过操纵战局操纵价格 | 玩家能通过干涉将军来影响指令价格 |
| **高风险高回报** | 杠杆放大收益也放大风险 | 存在"一夜暴富"和"瞬间爆仓"的可能 |
| **可预测的不确定性** | 结果不可完全控制，但可通过信息判断概率 | 玩家能根据将军性格预判行为，但仍有意外 |
| **道德灰度** | 最赚钱的策略往往伴随道德代价 | "做空国运"是有效且诱人的策略 |

# 二、核心循环

## 2.1 循环结构

```
┌─────────┐     ┌─────────┐     ┌─────────┐     ┌─────────┐
│  判断   │ ──→ │  布局   │ ──→ │  操纵   │ ──→ │  收割   │
└─────────┘     └─────────┘     └─────────┘     └─────────┘
     ↑                                               │
     └───────────────────────────────────────────────┘
```

## 2.2 各阶段说明

### 判断阶段

**玩家行为**：观察战局状态、将军意图、市场价格

**关键信息**：
- 各战线的接触/脱离状态 → 预判消耗强度
- 将军性格与当前状态 → 预判默认意图
- 市场流通盘 → 预判价格波动空间

**设计意图**：让玩家感觉"信息都在那里"，考验的是分析能力而非运气

### 布局阶段

**玩家行为**：通过金融工具建立仓位

**可用工具**：
- 买入现货 → 准备干涉，或囤货待涨
- 卖出现货 → 获利了结，或打压价格
- 做多期货 → 杠杆赌涨
- 做空期货 → 杠杆赌跌

**设计意图**：提供多样化的金融策略，让玩家有"操盘手"的感觉

### 操纵阶段

**玩家行为**：通过干涉将军来影响战局

**干涉方式**：
- 不作为 → 让将军执行默认意图（免费）
- 强化 → 提升将军战术效果（消耗现货）
- 篡改 → 强制改变将军行动（消耗更多现货）

**设计意图**：将金融资产与战场行动连接，指令既是金融商品也是战术资源

### 收割阶段

**玩家行为**：观察战斗结果，看仓位盈亏

**结果来源**：
- 战斗消耗指令 → 流通盘变化 → 价格变动
- 战线推进/后退 → 市场情绪变化 → 价格变动
- 期货到期 → 强制结算盈亏

**设计意图**：让玩家清晰感受到"我的操作导致了这个结果"

# 三、主要系统

## 3.1 金融市场系统

### 设计意图

让指令成为**金融衍生品**而非单纯的"弹药"。价格由市场因素决定，玩家可以通过理解市场规律获利。

### 核心机制：三因子定价

价格不是简单的供需关系，而是由三个因子共同决定：

| 因子 | 反映内容 | 设计意图 |
|------|----------|----------|
| **Alpha (基本面)** | 战局状态：接触/脱离、交战位置 | 让战场情况直接影响价格 |
| **Beta (情绪)** | 市场动量、恐慌程度 | 制造追涨杀跌、恐慌抛售等现象 |
| **Gamma (流动性)** | 流通盘充裕程度 | 支撑"垄断逼空"策略 |

### 核心机制：流通盘

- 流通盘是市场上可交易的指令总量
- 买入减少流通盘，卖出增加流通盘
- 流通盘接近零时，Gamma因子飙升，价格暴涨
- 军工厂每回合根据消耗量动态补充

**设计意图**：让"买断市场"成为可行策略，创造逼空玩法

### 核心机制：期货与做空

- 期货允许用少量保证金控制大额资产（杠杆效应）
- 做空允许玩家在价格下跌时获利
- 政权崩溃时指令价格归零，做空者获得最大收益

**设计意图**：提供高风险高回报的投机工具，支撑"做空国运"玩法

### 需要的参数

- 各指令基础价格
- 初始流通盘数量
- Alpha因子的战局修正表
- Beta因子的动量/恐慌阈值
- 期货保证金比例、强平线
- 军工厂产能系数

## 3.2 将军系统

### 设计意图

将军不是玩家的棋子，而是**有性格缺陷的NPC**。玩家需要理解他们的倾向，决定是否花钱干涉。

### 核心机制：默认意图

- 每回合开始，将军根据性格自动生成一个意图
- 不干涉时，将军免费执行默认意图
- 意图可能是明智的，也可能是愚蠢的（如残血冲锋）

**设计意图**：创造"是否干涉"的决策点，让现货既是金融资产也是干涉成本

### 核心机制：性格权重

三种性格决定了将军的行为倾向：

| 性格 | 特征 | 缺陷 |
|------|------|------|
| **狂热型** | 喜欢进攻 | 残血时更疯狂，拒绝撤退 |
| **保守型** | 喜欢防守 | 一掉血就想跑，推进缓慢 |
| **投机型** | 随机应变 | 难以预测 |

**设计意图**：让玩家能"预判"将军行为，但仍有不确定性

### 核心机制：状态修正

将军的兵力和位置会修正意图权重：

- 兵力越低 → 保守型更想撤退，狂热型反而更想冲锋
- 位于己方基地 → 撤退权重归零（退无可退）
- 位于敌方基地 → 进攻权重暴增（试图终结）

**设计意图**：创造戏剧性时刻，如"残血狂热者的送死冲锋"

### 核心机制：干涉

| 操作 | 消耗 | 效果 |
|------|------|------|
| 不作为 | 0 | 执行默认意图 |
| 强化 | 1份同类现货 | 提升战术效果 |
| 篡改 | 3份异类现货 | 强制改变意图 |

**设计意图**：现货消耗创造了"金融成本↔战术收益"的权衡

### 核心机制：信任度与抗命

- 篡改会降低信任度
- 信任度过低时，将军可能拒绝执行命令
- 抗命时，消耗的现货不退还

**设计意图**：限制无脑篡改，增加将军的"人格"感

### 需要的参数

- 各性格的基础意图权重
- 兵力状态对权重的修正
- 位置对权重的修正
- 信任度变化值
- 抗命概率阈值

## 3.3 战场系统

### 设计意图

战场是价格波动的来源。战斗越激烈，指令消耗越大，价格波动越剧烈。

### 核心机制：接触与脱离

战场状态分为两种：

| 状态 | 判定 | 指令用途 |
|------|------|----------|
| **脱离** | 双方不相邻 | 用于移动，消耗低 |
| **接触** | 双方相邻 | 用于战斗，消耗高 |

**设计意图**：接触状态 = 高消耗 = 价格上涨，创造可预测的市场规律

### 核心机制：指令对抗表

接触状态下，双方指令交互产生不同结果：

- ATK vs ATK → 遭遇战，双方损耗
- ATK vs DEF → 攻坚战，攻方损耗大
- ATK vs RET → 追击，攻方推进
- RET vs 任意 → 撤退方可回血

**设计意图**：创造石头剪刀布式的策略博弈

### 核心机制：战术星级

指令执行时会抽取具体战术：

| 星级 | 出现率 | 效果 |
|------|--------|------|
| 普通 | 高 | 标准效果 |
| 精锐 | 低 | 强化效果 |

强化操作会大幅提升精锐战术出现率。

**设计意图**：让"是否强化"成为有意义的决策

### 核心机制：战线联动

相邻战线会互相影响：

- 侧翼优势 → 加成
- 侧翼威胁 → 惩罚

**设计意图**：三条战线不是独立的，需要整体考虑

### 需要的参数

- 指令对抗表的伤害数值
- 战术星级的基础权重
- 强化对权重的修正
- 联动加成/惩罚数值

## 3.4 后备役系统

### 设计意图

后备役是国家的"生命线"，也是做空者关注的核心指标。

### 核心机制

- 所有回血/复活都消耗后备役
- 后备役耗尽后，无法回血，无法复活
- 后备役低时触发市场恐慌（Beta因子）

**设计意图**：创造"资源耗尽→崩溃"的死亡螺旋，为做空提供信号

### 需要的参数

- 初始后备役数量
- 各种回血/复活的消耗量
- 触发恐慌的阈值

## 3.5 维克多系统

### 设计意图

维克多是玩家在市场上的竞争对手，同时负责控制敌方将军。他与玩家遵循相同规则，是"垄断策略"的验证对象。

### 核心机制

- 维克多必须购买指令才能干涉敌方将军
- 玩家买光流通盘后，维克多无法采购
- 维克多买不到时，敌方将军只能执行默认意图

**设计意图**：验证"垄断"作为有效策略的可行性

### 需要的参数

- 维克多初始资金
- 维克多行为优先级

# 四、胜负框架

## 4.1 双轨制设计

游戏有两条独立的评判标准：

| 维度 | 判定标准 | 结果 |
|------|----------|------|
| **军事** | 战线占领 | 战役结束触发 |
| **财务** | 净资产达标 | 玩家是否获利 |

**设计意图**：解耦军事胜利与玩家成功，支撑"卖国求荣"玩法

## 4.2 四种结局

| 军事结果 | 财务达标 | 财务未达标 |
|----------|----------|-----------|
| **己方胜利** | 完美胜利 | 苦涩胜利（白忙） |
| **己方战败** | 冷血胜利（做空暴富） | 彻底失败 |

**设计意图**：让"冷血胜利"成为可能且诱人的结局

## 4.3 需要的参数

- 战役结束条件（占领/保持回合数）
- 目标净资产
- 最大回合数

# 五、原型验证目标

## 5.1 核心体验验证

| 验证目标 | 成功标准 |
|----------|----------|
| **市场与战场联动** | 玩家能感知"战斗激烈→价格上涨"的关系 |
| **垄断策略可行** | 玩家能通过买断流通盘限制维克多行动 |
| **做空策略可行** | 玩家能通过做空在战败时获利 |
| **干涉决策有意义** | 玩家会认真考虑"是否花钱干涉" |
| **将军性格可预判** | 玩家能根据性格预判将军行为 |

## 5.2 原型范围

### 必须包含

- 单条战线的战斗流程
- 三种指令的现货交易
- 三因子定价（至少简化版）
- 将军默认意图生成
- 强化/篡改干涉机制
- 期货做多/做空
- 维克多基础AI

### 可以简化

- 战术系统 → 可先用固定效果，不做星级抽取
- 联动系统 → 可先做单战线，不做联动
- 随机事件 → 可先不做
- 局外循环 → 可先做单局，不做存档

### 可以推迟

- 完整UI演出
- 音效系统
- 多战役配置
- 难度系统

## 5.3 关键数值平衡点

原型阶段需要重点调试：

| 平衡点 | 过高的问题 | 过低的问题 |
|--------|-----------|-----------|
| **流通盘** | 垄断太难，策略无效 | 垄断太容易，无挑战 |
| **杠杆倍数** | 风险太大，劝退玩家 | 不够刺激，无爽感 |
| **干涉成本** | 不舍得干涉，将军失控 | 随便干涉，无决策感 |
| **将军愚蠢程度** | 必须干涉，成本太高 | 不用干涉，系统无用 |

# 六、核心卖点总结

1. **你不是英雄，你是吸血鬼** —— 独特的道德定位
2. **战场即K线图** —— 金融与战争的创新融合
3. **做空国运** —— 极具冲击力的核心玩法
4. **将军有缺陷** —— 有趣的NPC性格系统
5. **高杠杆投机** —— 刺激的风险回报体验
