# 战争掮客 (The War Broker) - 系统重构与设计规范 (Final Version)

**文档目标**：
基于原有的“物流补给”原型，彻底重构为**“战争金融投机”**游戏。整合金融市场、局外循环、以及锡兵沙盘推演三大核心模块。

---

# 第一章：核心定义重构

## 1.1 从“商品”到“指数”

游戏中的核心交易物（ATK/DEF/RET）不再是实体弹药，而是**“战术指数 (Tactical Indices)”**。

| 原定义 | 新定义 | 玩家视角 |
| --- | --- | --- |
| **指令 (Order)** | **战术指数 (Index)** | 这是一个金融合约，代表市场对该战术价值的预期。 |
| **库存 (Inventory)** | **流通盘 (Float)** | 市场上的筹码总量。筹码越少，流动性溢价越高（越贵）。 |
| **消耗 (Consume)** | **行权/游说 (Lobby)** | 销毁手中的指数作为“政治献金”，强迫将军执行对应战术。 |
| **购买 (Buy)** | **建仓 (Long)** | 买入指数，期待升值或用于游说。 |
| **卖出 (Sell)** | **平仓 (Close)** | 卖出指数套现。 |

## 1.2 核心循环

1. **局外**：积累私人财富  支付战役门票  进入关卡。
2. **局内**：分析战局与舆论  交易指数获利  游说将军干涉战局  战争结算改变基本面  资产增值。

# 第二章：经济与市场系统 (The Market)

## 2.1 三因子定价模型

请废弃原有的“产出-消耗”简单供需逻辑，采用以下公式计算每回合的开盘价：


### A. 基本面因子 (Alpha)：战局客观价值

* **冲突烈度 (Intensity)**：基于战线位置的 U 型曲线。
* 战线在中间 (僵持)：价格回归基础值。
* 战线在两端 (决战)：ATK 和 DEF 的 Alpha 值大幅提升（战争白热化，需求刚性）。


* **信用评级 (Credit)**：基于将军状态（兵力/士气）。
* 将军兵力 > 15 (健康)：信用 AAA，对应指数溢价。
* 将军兵力 < 5 (濒死)：信用垃圾级，对应指数折价（除 DEF 外，DEF 可能因急需保命而反向溢价）。



### B. 情绪因子 (Beta)：市场非理性波动

* **动量 (Momentum)**：记录上一回合价格涨跌幅。若上回合大涨，本回合 Beta > 1.0 (追涨效应)。
* **恐慌 (VIX)**：
* 触发：单回合总伤亡 > 5 (25%) 或发生恶性随机事件。
* 效果：资金从 ATK 撤出，涌入 DEF/RET (避险)。



### C. 流动性因子 (Gamma)：供需挤压

* 计算公式：`标准流通盘 / 当前流通盘`。
* 效果：当玩家或 AI 买光市场上的筹码时，价格呈指数级暴涨 (逼空)。

## 2.2 全球投机者模拟 (The Global Crowd)

系统不直接改价格，而是每回合模拟三类 NPC 的买卖行为来改变**流通盘**：

1. **趋势猎人**：监测战线移动。战线推进  买入 ATK；战线停滞  卖出 ATK。
2. **价值投资者**：监测将军血量。将军受伤  抛售对应指数。
3. **秃鹫**：监测伤亡数。伤亡惨重  疯狂买入 DEF/RET。

## 2.3 金融工具调整

* **现货**：**唯一具有“行权”功能的资产**。必须持有现货才能干涉将军。买入会减少流通盘。
* **期货**：**纯投机工具**。现金交割，不能用于游说。支持**做空 (Short)**，这是玩家在下跌行情中赚钱的唯一手段。
* **借贷**：基于持仓市值的**保证金贷款**。若净资产过低，触发强平。

# 第三章：局外循环与战役配置 (Campaign)

## 3.1 资产结构

* **私人财富 (Private Wealth)**：玩家跨战役持有的总资金。
* **战役门票 (Entry Fee)**：进入关卡时扣除/冻结的本金。
* **低保机制**：若私人财富不足以支付最低门票，开放免费的“教学关”。

## 3.2 战役配置表 (CampaignConfig)

每个关卡是一个 ScriptableObject，包含：

* **市场参数**：初始流通盘大小（决定控盘难易度）、每回合发行量。
* **战场拓扑**：战线数量（1条/3条/5条）、初始战线位置。
* **将军配置**：初始兵力（满编 20）、初始性格。
* **AI 风格**：维克多是“保守型”（提供流动性）还是“秃鹫型”（主动做空）。

## 3.3 胜利与失败

* **胜利**：战役结束时，`局内净资产 > 目标金额`。返还门票并获得利润。
* **失败**：
* **破产**：现金 < 0。
* **审计清算**：违规操作过多（审计值满）。
* **业绩不达标**：结束时未赚够目标金额（仅退还部分本金）。

# 第四章：回合流程与交互 (The Loop)

采用**非同步回合制**。流程严格按以下顺序执行：

## 阶段 I：情报 (Briefing)

1. **事件结算**：显示随机事件（如“暴雨”）。
2. **意图公示**：将军根据性格预选战术（在将军头顶显示灰色图标）。
3. **开盘**：根据昨夜战况公示今日价格。

## 阶段 II：操盘 (Player Action)

玩家自由操作时间：

1. **交易**：买卖现货/期货。
2. **游说 (Lobbying)**：
* **顺势**（符合将军意愿）：拖拽 **1** 份现货给将军。消耗 1 份库存。
* **逆势**（强迫将军）：拖拽 **3** 份现货给将军。消耗 3 份库存，且将军**信任度大幅下降**。
* *注：必须持有现货才能游说。*



## 阶段 III：博弈 (Victor's Turn)

玩家点击“结束回合”后，AI (维克多) 行动：

* 根据市场情况进行买卖（可能砸盘玩家刚买入的指数）。
* *表现*：UI 上的价格板数字快速跳动。

## 阶段 IV：推演 (Resolution) - *见第五章*

## 阶段 V：结算 (Settlement)

1. **财务**：扣除贷款利息，计算期货盈亏。
2. **基本面重置**：根据刚刚结束的战斗结果，更新 Alpha/Beta 因子。
3. **胜负检测**：检查是否破产或达成战役目标。

# 第五章：战场与沙盘演义 (The Battlefield)

## 5.1 视觉风格：锡兵沙盘 (Tin Soldiers)

* **场景**：一张复古的红木办公桌。左侧是账本和行情单（UI），右侧是 3D 战争沙盘。
* **单位表现**：
* **满编 (20 HP)**：一个底座上站着 **20 个** 精致的锡兵模型。
* **受损**：随着 HP 下降，锡兵数量减少（每 1 HP 对应 1 个锡兵）。
* **濒死 (Low HP)**：底座上只剩 1 个锡兵，且身上有做旧/磨损效果。



## 5.2 数值平衡调整 (基于 20 HP 满编)

| 指令对抗 | 结果描述 | 数值伤害 (参考) | 战线移动 |
| --- | --- | --- | --- |
| **ATK vs ATK** | **血肉磨坊**。双方都试图进攻，伤亡惨重。 | 双方各 **-4** HP | 不移动 |
| **ATK vs DEF** | **攻坚战**。进攻方受挫，防守方轻伤。 | 攻方 **-2**，守方 **-1** | 不移动 |
| **ATK vs RET** | **追击**。撤退方成功脱离，但放弃阵地。 | 攻方 0，退方 0 | **攻方 +1** |
| **DEF vs DEF** | **静坐战**。无事发生。 | 双方 0 | 不移动 |
| **DEF vs RET** | **有序撤离**。 | 双方 0 | **守方(未动者) +1** |

* **技能/暴击**：特殊情况下（如将军技能触发），伤害可提升至 **-6 ~ -8**（直接打掉一排锡兵）。
* **溃败机制**：当 HP < 2 时，该部队强制撤离沙盘，该战线暂时空缺（极度危险状态）。

## 5.3 演出流程 (Sequence)

不需要复杂的镜头调度，保持上帝视角，强调**“玩具棋子的生硬感”**。

1. **指令揭示**：双方锡兵头顶同时翻开战术牌（ATK/DEF/RET）。
2. **攻击结算**：
* 执行攻击的一方，锡兵枪口冒出一团棉花状的烟雾 (VFX)。
* 音效：清脆的玩具枪声或发条声 (SFX)。


4. **伤亡结算**：
* 受损一方的底座上，对应数量的锡兵**直挺挺地向后倒下**，或者直接**消失**。
* 音效：木头/金属棋子倒在桌面的碰撞声。


5. **战线移动**：
* 若战线变化，整个底座以“跳棋”的方式跳到下一格。
* 音效：棋子在棋盘上滑动的摩擦声。

# 第六章：UI 与交互规范

## 6.1 术语本地化

为强化金融感，界面文本需做以下替换：

* `库存`  `持仓 (Holdings)`
* `购买`  `建仓 (Long)`
* `分配`  `游说 (Lobby)`
* `兵力`  `兵团规模 (Strength)`
* `健康度`  `信用评级 (Credit)`

## 6.2 舆论系统 (KOL)

在交易面板增加“市场情报”跑马灯，由三位 NPC 播报：

* **[趋势]**：“东线突破！动能指标爆表，建议追多 ATK。”
* **[价值]**：“近卫军受损严重，资产评级下调至 B-。”
* **[秃鹫]**：“恐慌指数上升，避险资金正在涌入 RET。”

## 6.3 游说反馈

当玩家拖拽现货进行游说时：

* 若**顺势**：连线显示为绿色，消耗 `x1`。
* 若**逆势**：连线显示为红色，消耗 `x3`，并弹出警告文本 **“强行干涉！成本 x3，信任度将下降”**。

# 第七章：开发优先级建议

1. **第一步 (Data)**：修改 `GameBalanceConfig` 和 `MarketSystem`，移除旧的损耗逻辑，实现 Alpha/Beta/Gamma 定价公式。
2. **第二步 (Logic)**：重写 `GameplayManager`，将分配指令改为“游说扣除持仓”逻辑。
3. **第三步 (Vis)**：搭建简单的 3D 场景，制作 20 HP 的锡兵底座预制体，实现“倒下/减少”的逻辑。
4. **第四步 (Campaign)**：实现局外资产存档和战役配置读取。
