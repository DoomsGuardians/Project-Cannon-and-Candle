# 战争掮客 (The War Broker)

## 系统设计策划案 v4.0

---

# 第一章：核心概念

## 1.1 游戏定位

回合制金融投机策略游戏。玩家扮演拿破仑战争时期的军需掮客，通过操纵战局影响军需品价格，从价格波动中获利。

## 1.2 核心幻想

> "战场是我的K线图，士兵的生命是我的筹码。"

## 1.3 核心循环

```
判断 → 布局 → 操纵 → 收割

判断：观察战局，预测价格走向
布局：通过金融工具建立仓位
操纵：通过指令分配影响战局
收割：价格变动，仓位盈亏
```

## 1.4 设计支柱

| 支柱 | 含义 |
|------|------|
| 市场与战场联动 | 战局→需求→价格，玩家可操纵战局来操纵价格 |
| 高风险高回报 | 杠杆放大收益也放大风险 |
| 不确定性 | 敌方行为、将军抗命、随机事件让结果不可完全控制 |
| 道德灰度 | 最赚钱的策略往往伴随最大的道德代价 |

# 第二章：世界观

1812年欧洲大陆。军需指令交易所中：
- **军工厂**生产标准化作战指令
- **掮客**（玩家与竞争对手）买卖指令
- **将军**是最终消费者

玩家受雇代理指挥作战，目标是在战役中为自己赚取最多财产和信用。

## 三种指令

| 指令 | 代号 | 功能 |
|------|------|------|
| 进攻令 | ATK | 命令军队进攻 |
| 防守令 | DEF | 命令军队固守 |
| 撤退令 | RET | 命令军队撤退 |

# 第三章：胜负条件

## 3.1 战争结束条件

| 条件 | 结果 |
|------|------|
| 三条战线均到达5并保持1回合 | 己方胜利 |
| 三条战线均到达1并保持1回合 | 敌方胜利 |
| 三条战线己方连续3回合未移动 | 谈判停战 |

## 3.2 玩家失败条件

| 条件 | 触发 |
|------|------|
| 破产 | 净资产为负 |
| 战争问责 | 审计值达到100 |

## 3.3 净资产计算

```
净资产 = 现金 + 指令库存市值 + 期货浮动盈亏 - 银行债务
```

## 3.4 审计系统

| 行为 | 审计值变化 |
|------|-----------|
| 军需总部补足指令（资金不足） | +30 |
| 己方将军溃败 | +20 |

审计值达到100触发战争问责，游戏失败。

```
            ↓

│  6. 市场更新                    │
│  7. 检查胜负条件                │
└─────────────────────────────────┘
```

# 第五章：市场系统

## 5.1 现货市场

买卖指令，即时交割。

**买入**：支付价格+手续费，获得指令，市场价上涨  
**卖出**：提供指令，获得价格-手续费，市场价下跌

**交易成本**：
- 手续费：交易额 × 2%
- 价格冲击：每买/卖1张 → 价格 ±2%

## 5.2 期货市场

买卖标准化期货合约，到期结算。

| 参数 | 说明 |
|------|------|
| 标的 | ATK / DEF / RET |
| 方向 | 做多 / 做空 |
| 到期 | 1/2/3回合后 |
| 保证金 | 合约价值的20%（5倍杠杆）|
| 强平线 | 亏损超过80%时强制平仓 |

**结算方式**：
```
做多盈亏 = (到期现货价 - 开仓价) × 数量
做空盈亏 = (开仓价 - 到期现货价) × 数量
```

## 5.3 银行借贷

| 参数 | 说明 |
|------|------|
| 利率 | 5%/回合（复利）|
| 额度 | 净资产 × 1.5 - 当前债务 |
| 限制 | 净资产为负时无法借款 |

## 5.4 持有成本

每回合结算：仓储费 = 持有指令总数 × $3

## 5.5 价格形成

```
价格 = 基础价格 × 供需比^弹性系数 × (1 + 随机波动)
随机波动 = ±5%
```

**需求来源**：己方将军状态、敌方将军状态、战场态势、随机事件

**库存变化**：
```
本回合库存 = 上回合剩余 + 军工厂产能 + 玩家卖出 + 维克多卖出 - 玩家买入 - 维克多买入
```

**军工厂产能**（每回合）：ATK 3张 / DEF 3张 / RET 2张

## 5.6 市场情报面板

显示所有影响价格的因素：

**上涨因素**：
- 将军状态恶化 → 对应指令需求上升
- 战线劣势 → DEF/RET需求上升
- 维克多囤货 → 供应减少
- 随机事件（如工厂事故）

**下跌因素**：
- 将军状态良好 → 需求正常
- 战线优势 → ATK需求下降
- 军工厂产能恢复
- 随机事件（如物资援助）

# 第六章：将军系统

## 6.1 配置

- 己方将军：3位，玩家负责供给指令
- 敌方将军：3位，维克多负责供给指令

## 6.2 将军属性

### 固定属性

| 属性 | 说明 |
|------|------|
| 姓名 | 将军名字 |
| 性格 | 狂热型 / 保守型 / 投机型 |
| 所属战线 | 左翼 / 中军 / 右翼 |
| 技能 | 2个（从性格技能池随机）|

### 动态属性

| 属性 | 范围 | 说明 |
|------|------|------|
| 兵力 | 0-100 | 部队规模，影响战斗力 |
| 信任度 | 0-100 | 对玩家的信任（玩家不可见）|
| 士气 | 0-100 | 战斗意志 |

### 综合状态

```
综合评分 = 兵力×0.4 + 信任度×0.3 + 士气×0.3
```

| 状态 | 综合评分 |
|------|---------|
| 健康 | >70 |
| 受伤 | 50-70 |
| 濒死 | 30-50 |
| 溃败 | <30 或 兵力<20 |

## 6.3 兵力

**变化规则**：

| 事件 | 兵力变化 |
|------|---------|
| 战斗胜利 | +10~20 |
| 战斗平手 | -5~10 |
| 战斗失败 | -15~30 |
| ATK对撞 | 额外-10 |
| 执行RET | 仅-5 |

**补员机制**：
```
每回合补员 = 基础补员(10) × 战线位置系数

战线位置系数：
  己方腹地（1-2）：×1
  中线（3）：×0.5
  敌方腹地（4-5）：×0
```

**兵力对战斗力影响**：

| 兵力 | 战斗力修正 | 限制 |
|------|-----------|------|
| 80-100 | ×1.0 | 无 |
| 50-79 | ×0.9 | 无 |
| 20-49 | ×0.7 | 无法主动ATK |
| <20 | - | 触发溃败 |

## 6.4 信任度（隐藏属性）

**变化规则**：

| 事件 | 变化 |
|------|------|
| 给正出价指令 | +5~10 |
| 给零出价指令 | +0~2 |
| 给负出价指令 | -10~15 |
| 因指令战斗失败 | -5 |
| 因指令战斗胜利 | +5 |

**信任度影响**：

| 信任度 | 效果 |
|--------|------|
| 80-100 | 出价慷慨 |
| 50-79 | 正常 |
| 30-49 | 出价苛刻，20%概率抗命 |
| 0-29 | 出价极苛刻，50%概率抗命 |

**抗命**：将军拒绝执行指令，自行选择行动，玩家已支付的钱不退还。

## 6.5 士气

**变化规则**：

| 事件 | 变化 |
|------|------|
| 战斗胜利 | +10~15 |
| 战斗失败 | -10~20 |
| 收到想要的指令 | +5 |
| 收到不想要的指令 | -5 |
| 友军溃败 | -10 |

**士气影响**：

| 士气 | 效果 |
|------|------|
| 80-100 | 战斗力+10% |
| 50-79 | 正常 |
| 30-49 | 战斗力-10% |
| 0-29 | 战斗力-20%，可能不战自溃 |

## 6.6 将军性格与出价

| 性格 | ATK偏好 | DEF偏好 | RET偏好 |
|------|---------|---------|---------|
| 狂热型 | 极高 | 低 | 厌恶 |
| 保守型 | 低 | 高 | 中 |
| 投机型 | 视战局 | 视战局 | 视战局 |

**出价计算**：
```
出价 = 基础值 × 性格系数 × 状态系数 × 信任度系数
基础值 = 市场价 × 0.3
```

正出价：将军付钱给玩家  
负出价：玩家付钱给将军

## 6.7 将军技能

每位将军从对应性格池中随机获得2个技能。

### 狂热型技能池

| 技能 | 触发条件 | 效果 |
|------|----------|------|
| 先登 | ATK获胜 | 额外战线+1 |
| 嗜血 | 连续2回合ATK | 第二次战斗力+20% |
| 死战 | 兵力<30时ATK | 战斗力+50%，额外损失10兵力 |
| 不退 | 被指派RET | 30%概率抗命改DEF |

### 保守型技能池

| 技能 | 触发条件 | 效果 |
|------|----------|------|
| 铁壁 | DEF成功抵挡ATK | 敌方额外损失5兵力 |
| 以逸待劳 | 连续2回合DEF | 下次被攻击反伤50% |
| 断后 | 执行RET | 兵力损失减半，士气不降 |
| 怯战 | 被指派ATK且兵力<50 | 20%概率抗命改DEF |

### 投机型技能池

| 技能 | 触发条件 | 效果 |
|------|----------|------|
| 顺风浪 | 战线≥4时ATK | 战斗力+30% |
| 逆风苟 | 战线≤2时DEF | 防御+30% |
| 诈败 | 执行RET且士气>60 | 敌方追击额外损失10兵力 |
| 见机行事 | 任意指令 | 根据敌方指令微调效果 |

## 6.8 强制分配

每回合结束前，玩家必须给3位己方将军各分配1张指令。

库存不足时必须购买。资金不足时军需总部补足指令，审计值+30。第二次触发直接失败。

## 6.9 溃败处理

将军溃败时：
1. 离开战场
2. 该战线暂时无人防守
3. 3回合后新将军抵达（初始属性较低）
4. 审计值+20

# 第七章：战场系统

## 7.1 战场结构

```
三条战线独立运作，有联动加成

     左翼 ─── 中军 ─── 右翼

每条战线范围：1-5
  1 = 逼近己方总部
  3 = 中间僵持
  5 = 逼近敌方总部
```

## 7.2 战线联动

| 态势 | 条件 | 效果 |
|------|------|------|
| 侧翼支援 | 相邻友军战线 ≥ 己方+1 | 战斗力+10% |
| 侧翼威胁 | 相邻敌军战线 ≥ 己方+1 | 战斗力-10%，士气-5 |
| 半包围 | 两侧友军战线都 ≥ 4 | 中路战斗力+25% |
| 被包围 | 两侧敌军战线都 ≤ 2 | 中路士气-15 |

## 7.3 战斗结算

### 结算流程

1. 收集双方将军指令
2. 计算双方战斗力
3. 确定战线移动
4. 更新将军状态

### 指令对抗表

| 己方 | 敌方 | 战线移动 | 己方伤害 | 敌方伤害 |
|------|------|---------|---------|---------|
| ATK | ATK | 0 | 中 | 中 |
| ATK | DEF | 0 | 轻 | 轻 |
| ATK | RET | +1 | 无 | 无 |
| DEF | ATK | 0 | 轻 | 轻 |
| DEF | DEF | 0 | 无 | 无 |
| DEF | RET | 0 | 无 | 无 |
| RET | ATK | -1 | 无 | 无 |
| RET | DEF | 0 | 无 | 无 |
| RET | RET | 0 | 无 | 无 |

### 战斗力计算

```
战斗力 = 基础值 × 兵力修正 × 士气修正 × 联动修正 × 随机修正

随机修正 = 0.75 ~ 1.25
暴击（5%概率）：×1.5
失误（5%概率）：×0.5
```

## 7.4 不确定性来源

| 来源 | 说明 |
|------|------|
| 敌方指令 | 维克多给敌方将军的指令未知 |
| 随机修正 | ±25%波动 + 暴击/失误 |
| 将军技能 | 可能触发特殊效果 |
| 将军抗命 | 低信任度时可能不执行命令 |
| 随机事件 | 可能突然改变战况 |

# 第八章：维克多系统

## 8.1 角色定位

维克多·克劳斯是玩家在市场上的竞争对手，同时负责敌方将军的指令供应。

## 8.2 属性

| 属性 | 说明 |
|------|------|
| 现金 | 可用资金 |
| 库存 | 持有的指令 |
| 判断力 | AI决策质量（可调难度）|

## 8.3 行为

- 根据敌方将军需求购买指令
- 观察市场趋势，低买高卖
- 可能与玩家抢购稀缺资源

# 第九章：随机事件系统

## 9.1 触发规则

每回合开始40%概率触发一个随机事件，同一事件不连续出现。

## 9.2 事件列表

### 市场类

| 事件 | 效果 | 持续 |
|------|------|------|
| 军工动员 | 产能+50% | 1回合 |
| 工厂事故 | 产能-50% | 1回合 |
| 补给线中断 | 某类指令不生产 | 1回合 |
| 物资援助 | 库存+10张 | 即时 |

### 战场类

| 事件 | 效果 | 持续 |
|------|------|------|
| 敌军增援 | DEF需求+50% | 2回合 |
| 我军增援 | ATK需求+30% | 2回合 |
| 和谈传闻 | 所有需求-30% | 2回合 |
| 瘟疫爆发 | 所有将军兵力-20 | 即时 |
| 叛变事件 | 随机将军信任度-30 | 即时 |
